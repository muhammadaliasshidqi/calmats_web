# Audit antislop CALMATS

Audit baca-saja pada source Blade, CSS, JavaScript, dan konfigurasi. Temuan ini belum dikonfirmasi lewat browser, pembaca layar, atau pengukuran kontras otomatis. Tidak ada file aplikasi yang diubah.

## Prioritas HIGH

1. **Form belanja memakai placeholder sebagai pengganti label yang terlihat.** Di `resources/views/cart.blade.php`, nama, nomor WhatsApp, alamat, dan catatan tidak memiliki `<label>` yang terlihat. Placeholder menghilang saat pengguna mengisi, sehingga nama bidang tidak terus tersedia. **R-39.**

2. **Menu seluler memiliki nama aksesibel statis yang tidak cocok dengan status.** Tombol di `resources/views/components/navbar.blade.php` selalu bernama “Buka menu” ketika panel terbuka dan tidak menghubungkan tombol dengan panel memakai `aria-controls`. Hal ini menyulitkan pengguna teknologi bantu memahami tindakan berikutnya. **R-39.**

3. **Teks kecil pada permukaan gelap berisiko gagal kontras AA.** Kelas seperti `text-paper/40`, `/45`, dan `/50` dipakai untuk placeholder dan teks status pada latar gelap di cart/community; opacity ini menurunkan kontras. Nilai aktual belum diuji dengan tool kontras. **R-25, R-39.**

4. **Menu dropdown kustom belum menunjukkan dukungan tombol panah dan Escape secara jelas.** `resources/views/components/select-dropdown.blade.php` mengimplementasikan listbox dengan tombol dan state Alpine. Source menunjukkan fokus awal ke item terpilih, tetapi belum tampak penanganan Escape/arrow-key atau pemulihan fokus setelah ditutup. Perlu verifikasi interaksi keyboard. **R-32, R-39.**

5. **Media belum konsisten memiliki dimensi eksplisit.** Komponen gambar memakai class rasio/aspect pada sebagian pemanggil, tetapi tidak semua elemen media punya `width`/`height` atau aturan rasio yang konsisten. Gambar utama hero juga dimuat melalui komponen lazy-load, bukan eager dengan `fetchpriority="high"`. **R-40.**

## Prioritas MEDIUM

6. **Beberapa klaim identitas/produk tampil sebagai fakta tanpa bukti di repo.** Misalnya “Designed in Indonesia”, “Indonesian streetwear personality”, dan uraian asal-usul merek. Konfirmasi sumbernya sebelum menyajikannya sebagai fakta. **R-36, R-38, C-5.**

7. **Pola visual memakai tekstur titik dan beberapa lapisan dekoratif.** `resources/css/app.css` memberi pola radial titik pada seluruh `.premium-page`, serta panel dengan gradient, garis berulang, dan shadow. README memberi arah merek, tetapi alasan spesifik untuk tiap teknik belum tertulis. **R-01, R-07, R-12, R-31.**

8. **Radius tombol/input sangat seragam berbentuk pil.** Tombol umum `.btn` dan berbagai kontrol katalog/cart memakai `rounded-full`, sehingga bentuk tidak banyak membedakan jenis kontrol. **R-11.**

9. **Status UI async belum selalu terlihat.** Sinkronisasi cart berjalan melalui fetch, tetapi kegagalan ditelan dan tidak ada status loading/error yang ditampilkan. Interaksi cart tetap tersedia lokal, namun kegagalan sinkronisasi akun tidak dijelaskan pada UI. **R-27, C-4.**

10. **Audit mobile dan fungsi belum dapat dipastikan dari inspeksi source.** CSS membatasi overflow dan menyesuaikan tombol, tetapi tidak ada bukti pemeriksaan tiap breakpoint. Delivery Gate mensyaratkan menjalankan aplikasi dan click-through kontrol, termasuk menu, filter, varian, cart, dan formulir. **R-03, R-26, R-35.**

## Prioritas LOW

11. **Arah visual belum menetapkan dial antislop secara eksplisit.** README mendokumentasikan palet, font, dan prinsip komposisi, namun tidak menyatakan ENERGY/RHYTHM/MOTION atau satu baris Design Read. **R-31, R-37.**

12. **Panah dekoratif berulang pada beberapa CTA.** Simbol `→` tampil pada tautan koleksi dan keranjang. Fungsinya dapat dipahami sebagai penunjuk navigasi, tetapi alasan pemakaian dan konsistensinya belum dicatat. **R-08, R-31.**

## Batas audit

- Pencarian source menemukan skip link, landmark utama, `lang="id"`, focus-visible, dan aturan reduced-motion.
- Tidak ditemukan `DESIGN.md`, `AGENTS.md`, maupun laporan audit antislop terdahulu di root proyek.
- Nama “ponytail” tidak cocok dengan skill yang tersedia pada sesi ini; skill antislop UI, human/accessibility, layoutmobile, copywriting, dan code sudah ditinjau sebagai bahan audit.
- Audit ini belum menjalankan build atau browser click-through, sehingga temuan yang memerlukan bukti runtime ditandai sebagai perlu verifikasi, bukan klaim kegagalan yang teramati.
- `composer.lock` dan `package-lock.json` sudah berubah sebelum audit; perubahan tersebut tidak saya sentuh.
